# Hearthplan

Hearthplan is an independent planning tool for Old School RuneScape player-owned houses. [Open the planner](https://osrskoeppy.github.io/Hearthplan/).

Lay out a house across three floors, enter rooms to choose furniture, and check off each upgrade as you build it in game. The planner keeps a full estimate and a remaining shopping list. It saves plans in your browser and supports JSON plan backups and CSV supplies exports.

The 3D previews use original schematic artwork. Room and furniture data are adapted from the [Old School RuneScape Wiki](https://oldschool.runescape.wiki/w/Player-owned_house) under [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/). Estimated market prices use the [OSRS Wiki price feed](https://prices.runescape.wiki/osrs/).
